# Demon Slayer: The Three Upper Moons

A beautiful aesthetic website dedicated to the Upper Moons from Demon Slayer, featuring sections for Akaza (3rd), Douma (2nd), and Kokushibo (1st) with eye images and animated galleries.

## Description

This website showcases the three Upper Moons with stunning visuals. It has no direct practical use; I created it simply to have a beautiful website.

## How to View

Simply open `index.html` in your web browser.
